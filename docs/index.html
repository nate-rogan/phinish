How it works
01

You file an issue

Pick a date and venue. The form opens a pre-filled GitHub issue.

02

Actions runs

The predict label fires a workflow on GitHub's runners.

03

Ensemble scores

XGBoost + Markov + gap heuristic + venue history vote on each song.

04

Comment posted

The setlist appears as a comment with calibrated confidences. Issue closes.
